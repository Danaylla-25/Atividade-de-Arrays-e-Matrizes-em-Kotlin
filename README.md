# Atividade-de-Arrays-e-Matrizes-em-Kotlin
Repositório desenvolvido para a resolução da atividade prática sobre vetores unidimensionais (Arrays) e matrizes bidimensionais em Kotlin.

## Sobre o Projeto
Este projeto reúne 10 exercícios práticos divididos em dois blocos, explorando o armazenamento e a manipulação de dados estruturados com laços de repetição (`for`, `while`), laços aninhados e controle de fluxo (`break`, `continue`).

## Exercícios Resolvidos

### Bloco I: Arrays Unidimensionais
1. **Inversão de Vetor:** Inversão dos elementos de um `IntArray` usando `while` e troca de extremos sem vetor auxiliar.
2. **Busca e Interrupção:** Pesquisa de códigos de transação em um array de `String` com interrupção imediata usando `break`.
3. **Média de Temperaturas:** Cálculo da média semanal em um `DoubleArray` e filtragem dos dias acima da média.
4. **Filtragem de Pares com Step:** Soma de elementos em índices pares utilizando `for` com `step 2`.
5. **Listagem com Índices:** Exibição numerada de tarefas combinando `for` e `.withIndex()`.

### Bloco II: Matrizes Bidimensionais
6. **Soma por Linhas:** Cálculo individual da soma de cada linha em uma matriz `3x4`.
7. **Matriz Transposta:** Conversão de uma matriz `2x3` para sua transposta `3x2` invertendo linhas e colunas.
8. **Análise de Diagonais:** Exibição de uma matriz quadrada `4x4` e soma exclusiva da diagonal principal.
9. **Identificação de Zeros com Continue:** Soma de valores positivos em uma matriz `3x3`, ignorando zeros com `continue`.
10. **Boletim de Alunos:** Cálculo de média individual, status de aprovação (`if / else`) e média geral da turma em uma matriz `3x2`.

## Tecnologias e Conceitos
* **Linguagem:** Kotlin
* **IDE:** VS Code
* **Conceitos:** `Array`, `IntArray`, `DoubleArray`, matrizes (`Array<IntArray>` / `Array<DoubleArray>`), laços aninhados, `break`, `continue`, `step` e `.withIndex()`.

## Como Executar
1. Clone este repositório.
2. Abra o projeto na sua IDE Kotlin.
3. Acesse o arquivo da questão desejada e execute a função `main()` para visualizar o resultado no console.
